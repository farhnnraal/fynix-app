# Design System

# Technology
Using Next.js, and TailwindCSS latest version. Sync with current project directory.

# Instruction
Create a page based on description. This page is for answering question from user, the layout is the same like chat app. There is a bubble chat from Gen AI and User. Create 3 different section which is header, main (where bubbles chat appear), and footer is field for typing the answer or prompt. The bubbles chat for Gen AI is Neutral-50 for background with Neutral-300 1px solid border, 24px corner radius, 16px padding and gap, the bubbles is 2 row, first for the chat, and second is for Gen AI profile picture. For User bubble chat is the same style as Gen AI bubble but just single row for text. In the footer which is prompt input field is rounded fill width with mic icon on the right side, it was Neutral-50 with Primary-500 1px solid border.
